## 1. ภาพรวมเชิงสถาปัตยกรรม (The Big Picture)

ระบบ **WorkDee** ถูกออกแบบให้เป็น **"HR Super App"** ประจำองค์กร โดยเชื่อมโยง 2 ส่วนประสานงานหลักเข้าด้วยกัน:

### 1.1 ช่องทางฝั่งพนักงาน (Mobile Touchpoint via LINE OA & LIFF)

เป็นหน้าต่างบริการตนเอง (Self-Service) ที่เข้าถึงง่าย **ไม่ต้องติดตั้งแอปพลิเคชันใหม่** เน้นความรวดเร็วในการทำธุรกรรมประจำวัน และรับการแจ้งเตือนแบบเฉพาะบุคคลผ่าน LINE

**ข้อดีเชิงกลยุทธ์:**
- ลดอุปสรรคการเข้าถึง (Adoption Barrier) ของพนักงานทุกระดับ
- ใช้ช่องทางที่พนักงานเปิดอ่านทุกวันอยู่แล้ว
- ลดต้นทุนการพัฒนาและบำรุงรักษาแอปมือถือแยก

### 1.2 ศูนย์บัญชาการฝ่ายบุคคล (HR Command Center via Web Admin)

เป็นระบบหลังบ้านสำหรับฝ่ายบุคคลและผู้บริหาร ใช้สำหรับ:
- จัดการโครงสร้างข้อมูลหลัก (Location, Policy, Employee Profile)
- กำหนดนโยบายและกติกาองค์กร
- ตรวจสอบรายการผิดปกติ (Flagged Review)
- ดูรายงานภาพรวมและส่งออกข้อมูล

### 1.3 ปรัชญาการออกแบบส่วนติดต่อผู้ใช้ (UI/UX Philosophy)

#### 1.3.1 ไม่ใช้คำสั่งพิมพ์ (No Command `@...`)

เพื่อลดความผิดพลาดจากตัวสะกด และลดความเหลื่อมล้ำทางทักษะไอทีของพนักงาน ระบบจะใช้ **ปุ่มกด (Button-based Interaction)** และ **Rich Menu** แทนการพิมพ์คำสั่งทั้งหมด

#### 1.3.2 แนวคิด Dock & Portal

ใช้ Rich Menu ด้านล่างเป็นเพียง **"ทางด่วน"** สำหรับงานที่ต้องกดทุกวัน (เช่น ลงเวลา) ควบคู่กับปุ่มเปิด **"ศูนย์รวมบริการทั้งหมด"** ที่รองรับการเพิ่มฟังก์ชันในอนาคตได้อย่างไร้ขีดจำกัดโดยไม่รกหน้าจอ

#### 1.3.3 ยืดหยุ่นแต่ตรวจสอบได้ (Flexible yet Auditable)

ระบบไม่ตัดสิทธิ์พนักงานทันทีเมื่อทำผิดเงื่อนไข แต่เน้น **การเก็บหลักฐานและเหตุผล** เพื่อให้ HR ตรวจสอบย้อนหลังได้อย่างเป็นธรรม

## 2. แผนผังยุทธศาสตร์การพัฒนา (Phased Roadmap)

การพัฒนาถูกแบ่งออกเป็น 3 ระยะตามลำดับความจำเป็นและการพึ่งพาของข้อมูล:

### Phase 0: ระบบลงเวลาอัจฉริยะ (The Urgent Attendance Foundation)

**โฟกัส:** สร้างระบบบันทึกเวลาทำงานด้วยพิกัด GPS ที่มีความยืดหยุ่นสูง เพื่อตอบโจทย์การใช้งานทันที

**เหตุผลที่ต้องเริ่มที่นี่:**
- เป็นข้อมูลพื้นฐาน (Foundation Data) ที่ Phase 1-2 ต้องใช้
- เป็น Pain Point อันดับต้นของ HR และพนักงาน
- มีความซับซ้อนพอที่จะพิสูจน์สถาปัตยกรรม แต่ไม่ผูกกับสายอนุมัติซับซ้อน

### Phase 1: การมีส่วนร่วมและการสื่อสาร (Engagement & Operations)

**โฟกัส:** งานสื่อสารและสนับสนุนพนักงานที่ไม่ต้องพึ่งพาสายการอนุมัติซับซ้อน

**ฟีเจอร์หลัก:**
- การกระจายข่าวสารแบบเจาะจงกลุ่ม (Targeted Broadcast)
- ระบบตอบคำถามอัตโนมัติ (HR FAQ Bot)
- ระบบส่งข้อเสนอแนะ/แจ้งปัญหาแบบไม่ระบุตัวตน

### Phase 2: เวิร์กโฟลว์และความปลอดภัยขั้นสูง (Sensitive Workflows & Approvals)

**โฟกัส:** งานที่มีเรื่องเงิน เอกสารสำคัญ และสายการบังคับบัญชา

**ฟีเจอร์หลัก:**
- ดูสลิปเงินเดือนอิเล็กทรอนิกส์ (e-Payslip)
- ยื่นคำขอหนังสือรับรอง (Document Requests)
- ระบบลางาน (Leave Management)
- ระบบอนุมัติผ่าน LINE สำหรับหัวหน้างาน
